# Student Information System

## Assignment
Software Design and Architecture - Assignment 1

## Language Used
Java

## Description
This project is a simple Student Information System designed using Object-Oriented Programming principles.

The project includes the following classes:
- Faculty
- Department
- Program
- Student
- Instructor
- Course
- AcademicTerm
- CoursePrerequisite
- ProgramCourse

The project also includes enum types for fields such as gender, student status, degree level, semester, course type, instructor title, prerequisite type, and program course type.

## Main Program
The main program:
- Creates an ArrayList of students.
- Creates sample Faculty, Department, Program, and Student objects.
- Registers a student by adding the Student object to the ArrayList.
- Prints the registered student information to the console.
